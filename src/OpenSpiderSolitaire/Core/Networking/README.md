# Core/Networking

Intentionally empty.

OpenSpiderSolitaire is a **fully offline** app (see `docs/PRD.md`): no ads, no
in-app purchases, no network calls, no accounts, no analytics, no iCloud sync.

This folder exists only to match the standard `Core/` layout defined in
`CLAUDE.md`. Do not add networking code here without revisiting the PRD's
offline constraint.
